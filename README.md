<h1> 📘 SQL Exercises & Generation </h1>

Um repositório dedicado a estudos, práticas e geração de consultas SQL.
Este projeto contém scripts SQL, exercícios e exemplos focados em bancos relacionais, incluindo criação de tabelas, manipulação de dados, consultas avançadas e integração com aplicações.

🧩 Sobre SQL
SQL (Structured Query Language) é a linguagem padrão utilizada para gerenciar e manipular bancos de dados relacionais.
Com ele é possível:

- Criar estruturas (tabelas, índices, chaves).
- Inserir, consultar, atualizar e deletar dados.
- Garantir integridade referencial.

Realizar consultas complexas com JOIN, GROUP BY, HAVING, subqueries etc.

Automatizar operações com views, procedures e triggers.
SQL é amplamente usado em sistemas web, análise de dados, APIs e praticamente qualquer solução que envolva armazenamento estruturado.


🚀 Como Clonar o Repositório
Abra o terminal (Git Bash, CMD, PowerShell ou terminal do VS Code)

Execute:
git clone https://github.com/NatanGraffitti/SQL_Exercises_Generation

Entre no diretório:
cd NOME_DO_DIRETORIO



🖥️ Como Executar o Projeto na Sua Máquina


✔️ Pré-requisitos

Você precisa ter instalado:
Git
SQLite, MySQL ou outro banco que esteja utilizando
(Opcional) VS Code + Extensão SQLTools

🔧 Rodando os arquivos SQL



🔹 Se estiver usando SQLite:

Abra o terminal dentro do repositório.

Inicie o console:
sqlite3 database.db

Execute o script de criação:
.read sql/create_tables.sql

Insira os dados:
.read sql/insert_data.sql

Rode suas consultas:
.read sql/queries.sql

🔹 Se estiver usando MySQL:

Abra o terminal do MySQL:
mysql -u root -p

🧪 Executando os Exercícios

Dentro da pasta /sql/exercises, você encontrará arquivos com desafios SQL.
Você pode abrir no VS Code ou rodar direto no terminal.
